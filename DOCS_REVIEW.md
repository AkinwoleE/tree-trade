# Docs review: existing code vs official docs

Scope: the code that existed before the Hedge work (Move oracle, exchange and tokens; keeper; web wallet
integration; trader and position discovery), checked against the official docs. "Replaced" means the custom code
now uses the documented helper.

| # | Area | Existing code | What the docs say | Verdict / action |
| --- | --- | --- | --- | --- |
| 1 | Wallet provider | `AptosWalletAdapterProvider autoConnect dappConfig={{network, aptosApiKeys}} onError` (`web/src/app/providers.tsx`) | Recommended setup: `autoConnect`, `dappConfig.network`, `aptosApiKeys` ([wallet-adapter/dapp](https://aptos.dev/build/sdks/wallet-adapter/dapp)) | Matches. No change. |
| 2 | Wallet list | Hand-rolled list of `wallets` plus the first 4 `notDetectedWallets` | Use `groupAndSortWallets(...)`, which splits Petra Web / Aptos Connect social login, installed and installable wallets | **Replaced** in `web/src/components/WalletButton.tsx`, now using `groupAndSortWallets` and `truncateAddress` (both exported by `@aptos-labs/wallet-adapter-react`). Social-login wallets now appear, which they did not before. |

## Summary of replacements

* `WalletButton` hand-rolled wallet grouping → `groupAndSortWallets` + `truncateAddress`; added `changeNetwork`.
* `useTx` generalised to the same documented wallet path for any entry function.
* Keeper: explicit `maxGasAmount` (ts-sdk v7 default change); trader discovery includes the hedge entry function; 429 retry.
* No redundant custom code found in the Move modules; the oracle is kept on purpose (row 12).
